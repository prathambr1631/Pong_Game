# 🏓 Pong Game

A classic two-player Pong game built using Python's built-in `turtle` graphics module.

## 🎮 Features

- Two-player gameplay
- Real-time paddle movement
- Ball collision detection
- Score tracking
- 60 FPS gameplay

## 🛠️ Technologies Used

- Python 3
- Turtle Graphics
- Time Module

## 🎮 Controls

### Player A
- **W** → Move Up
- **S** → Move Down

### Player B
- **↑ (Up Arrow)** → Move Up
- **↓ (Down Arrow)** → Move Down

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/prathambr1631/Pong_Game.git
```

2. Navigate to the project:

```bash
cd Pong_Game
```

3. Run the game:

```bash
python3 pong.py
```
